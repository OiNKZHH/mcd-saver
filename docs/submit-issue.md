## 项目简介

一个「会点餐」的麦当劳 AI Skill——先懂你想吃什么、为什么点，再带意图推荐。**省钱是约束，不是目标。**

基于麦当劳 MCP 能力平台（`auto-bind-coupons` / `query-nearby-stores` / `query-meals` / `query-store-coupons` / `list-nutrition-foods` / `calculate-price` 等 30+ 能力），实现了三层核心能力：

1. **会算**：把每个餐品建模为「多价格档位」（无券现价 + 券后价），用 0/1 背包 + 分支限界求解最优组合，再对 top-K 候选逐个调 `calculate-price` 用真实 `discount` 精排——纠正「菜单划线价是营销标注、真实省钱额在结算接口」的坑。

2. **会点**：点餐意图前置层，先问「健康 / 解馋 / 换口味 / 省钱 / 随便」，再按时段过滤（晚餐不推咖啡）、套餐品类去重（套餐含可乐就不再推饮料）、凑单保护（不为凑券而加购）做体验优化。

3. **会下单**：一键领券 → 查门店 → 组合优化 → 真实报价复核 → 生成下单方案。

**一句话亮点**：别的省钱助手只会算「怎么最便宜」，麦麦省粮管家先懂「你为什么点这一顿」。
